Customer Churn Analysis

Project Overview

This project analyzes customer churn data to identify why customers leave a company and understand customer retention patterns.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Excel

Project Objectives

- Analyze customer churn rate.
- Identify factors affecting customer churn.
- Compare monthly charges of churned and retained customers.
- Analyze customer demographics and service usage.
- Visualize key business insights using Power BI.

Project Files

- "Customer_Churn_Cleaned.csv" – Cleaned customer dataset
- Python code – Data cleaning and analysis
- Power BI dashboard – Customer churn visualization
- Charts and graphs – Data analysis results

Key Insights

- Customer churn rate
- Churn by contract type
- Monthly charges by churn status
- Churn by internet service
- Customer retention patterns

Conclusion

This project helps understand customer churn patterns and provides insights that can support customer retention strategies.
